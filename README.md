# Be Discipline

> A minimal, offline-first habit tracker and focus companion.

**Live site:** [https://misalignedink.github.io/bediscipline](https://misalignedink.github.io/bediscipline)

---

## Overview

**Be Discipline** is a lightweight, distraction-free productivity app built for consistency and daily momentum. It brings together daily habit tracking, quick tasks, and dedicated focus timers into a single, clean workspace.

Vibe coded for simplicity, speed, and privacy.

---

## Features

- **Habits & Streaks** — Track recurring routines, organize by category, and maintain consistency over time.
- **Daily Tasks** — Keep track of day-to-day priorities alongside your habits.
- **Focus Timers** — Integrated Pomodoro, countdown timer, and stopwatch to log deep work sessions.
- **Activity & Insights** — Visual activity heatmaps and completion trends to monitor progress.
- **Offline First** — PWA support with local browser storage. No accounts, no servers, and zero telemetry.
- **Adaptive UI** — Thoughtfully crafted for mobile and desktop, with native light and dark modes.

---

## Tech

- Pure HTML5 & Vanilla JavaScript
- Tailwind CSS (Utility-first styling)
- Instrument Sans font
- Lucide Icons
- Service Worker & Web App Manifest (PWA)

---

## Running Locally

No build step or dependencies required. Simply serve the directory locally or open `index.html` directly in your browser.

```bash
# Clone the repository
git clone https://github.com/misalignedink/bediscipline.git
cd bediscipline

# Start a local static server (e.g., Python 3)
python3 -m http.server 8000
```

Open `http://localhost:8000` in your browser.
